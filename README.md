# Machine-Readable XLSX

Government departments make heavy use of Excel workbooks for data collection, analysis, and reporting. However, Excel workbooks are not always machine-readable, which can be a barrier to automating data processing. This repository provides resources for creating machine-readable Excel workbooks.

## Repository Contents

- **ConcessionaryLoansAssessmentTemplate/**  
  Contains documentation and scripts relating to the "Concessionary Loans Assessment Template" spreadsheet. The template is designed to follow the best practices outlined in the documentation while catering to the needs of the concessionary loans assessment process.
